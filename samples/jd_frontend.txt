# 岗位名称：前端开发工程师（Vue 方向）

## 岗位职责
1. 负责公司核心 Web 产品的研发，与 UI/后端协作完成高质量交付。
2. 负责前端工程化建设，提升构建效率与代码质量。
3. 负责页面性能优化与首屏加载速度提升，持续改善用户体验。
4. 参与组件库建设与设计规范落地，沉淀可复用能力。

## 任职要求（必备）
1. 本科及以上学历，3 年以上前端开发经验。
2. 精通 JavaScript（ES6+）与 TypeScript。
3. 熟练使用 Vue 3 及其生态（Vue Router、Pinia），理解响应式原理。
4. 熟练掌握 HTML5 / CSS3，具备响应式布局与移动端适配经验。
5. 熟练使用前端构建工具 Vite / Webpack，理解打包优化策略。
6. 熟悉 HTTP 协议与浏览器渲染机制，具备性能优化实战经验。
7. 熟悉 Git 协作流程，具备良好的代码规范意识。

## 加分项（非必备）
1. 熟悉 React 并有跨框架开发经验。
2. 有 ECharts 等数据可视化开发经验。
3. 有 Node.js 服务端开发经验。
4. 有单元测试（Vitest / Jest）编写经验。
5. 有个人技术博客或开源项目。

## 我们提供
- 一线互联网技术栈与成长空间
- 完善的导师制与晋升通道
- 定期技术分享与团建活动
