# 岗位名称：Java 后端开发工程师（高级）

## 岗位职责
1. 负责公司核心业务系统的后端架构设计与开发，保障高并发场景下的稳定性与性能。
2. 参与微服务拆分与治理，持续优化服务间调用链路与数据一致性方案。
3. 负责数据库表结构设计与 SQL 性能优化，支撑千万级数据量业务。
4. 参与技术方案评审与代码评审，推动团队工程规范落地。

## 任职要求（必备）
1. 本科及以上学历，计算机相关专业，5 年以上 Java 后端开发经验。
2. 精通 Java，熟悉 JVM 内存模型与性能调优。
3. 熟练使用 Spring Boot、Spring Cloud 微服务框架。
4. 熟练使用 MySQL，具备索引优化与慢查询治理经验。
5. 熟悉 Redis 缓存设计与常见缓存问题（穿透/击穿/雪崩）解决方案。
6. 熟悉消息队列（RabbitMQ / RocketMQ / Kafka 任一），有异步解耦实战经验。
7. 熟悉 Linux 常用命令，具备线上问题排查能力。

## 加分项（非必备）
1. 有 Docker、Kubernetes 容器化部署经验。
2. 有 CI/CD（Jenkins / GitLab CI）流水线搭建经验。
3. 熟悉 Elasticsearch，有搜索结果调优经验。
4. 有高并发、分布式系统设计经验。
5. 有良好的英文技术文档阅读能力。

## 我们提供
- 具有竞争力的薪酬与期权激励
- 弹性工作制与扁平化技术氛围
- 参与从 0 到 1 的核心系统建设机会
